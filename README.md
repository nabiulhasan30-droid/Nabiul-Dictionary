# 📖 Nabiul Offline Dictionary (নবীউল অফলাইন অভিধান)

সম্পূর্ণ অফলাইন এবং সমৃদ্ধ অ্যান্ড্রয়েড অভিধান (Android Kotlin)। কোনো ইন্টারনেট সংযোগ ছাড়াই লক্ষাধিক শব্দের তাৎক্ষণিক অর্থ, উচ্চারণ এবং সমার্থক শব্দ অনুসন্ধান করা যায়।

## ✨ প্রধান বৈশিষ্ট্যসমূহ (Features):
* **৩টি শক্তিশালী সার্চ মোড:**
  1. 🇬🇧 ➔ 🇧🇩 **English to Bengali:** ১০৩,৬০০+ ইংরেজি শব্দের বিস্তারিত বাংলা অর্থ এবং পার্টস অব স্পিচ।
  2. 🇧🇩 ➔ 🇬🇧 **Bengali to English:** ৯৪,৩০০+ বাংলা শব্দের সঠিক ইংরেজি প্রতিশব্দ।
  3. 🇧🇩 ➔ 🇧🇩 **Bengali to Bengali:** ৪৬,৫০০+ খাঁটি বাংলা শব্দের বিশদ বাংলা অর্থ ও সমার্থক শব্দ (বাংলা একাডেমি ভিত্তিক)।
* ⚡ **সুপার ফাস্ট অফলাইন সার্চ:** অপ্টিমাইজড SQLite ও B-Tree ইনডেক্সিং এর মাধ্যমে মিলি-সেকেন্ডে তাৎক্ষণিক ফলাফল।
* 🔊 **অফলাইন অডিও উচ্চারণ (Text-to-Speech):** ইংরেজি ও বাংলা শব্দের নিখুঁত উচ্চারণ শোনার সুবিধা।
* 🔖 **বুকমার্ক / প্রিয় তালিকা:** প্রয়োজনীয় শব্দ সংরক্ষণ ও সহজে খোঁজা।
* 🕒 **অনুসন্ধানের ইতিহাস (Search History):** সাম্প্রতিক খোঁজা শব্দের তালিকা।
* 📋 **ক্লিপবোর্ড কপি:** এক ট্যাপে অর্থ কপি করা।
* 🎨 **মডার্ন মেটেরিয়াল ৩ UI:** মসৃণ এবং আকর্ষণীয় ইন্টারফেস।

## 🛠 প্রযুক্তি ও আর্কিটেকচার:
* **Language:** Kotlin
* **Architecture:** MVVM + Coroutines
* **Database:** Pre-packaged SQLite (36MB, 244,000+ words)
* **Audio Engine:** Android TextToSpeech (TTS)
* **Build System:** Gradle 8.2 + AGP 8.2.2
* **Permanent Keystore:** Consistent signature configuration for seamless updates without package conflict.
